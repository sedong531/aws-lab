IP라우트에서는 Longest Prefix Match, 최장 접두사 일치 규칙이 있음.
라우터가 목적지의 IP를 보고, 여러 라우트가 동시에 맞으면 가장 구체적인 네트워크 경로를 선택함.
10.0.0.0/16 -> Local
0.0.0.0/0 -> Internet Gateway
목적지가 10.0.2.5 라면? 둘다 매칭되지만, /16이 /0보다 더 구체적이므로 /16을 선택함. 
이는 일반적인 라우터나 리눅스라우팅, aws vpc 라우팅에서도 널리쓰이는 개념임. 일반적인 IP 라우팅 원칙임
